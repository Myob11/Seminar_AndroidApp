# SecureChat Android

SecureChat is an Android messaging app focused on private, end-to-end encrypted conversations. Users can create an account, find and add friends, manage incoming friend requests, and start direct chats. The app uses public-key exchange and locally stored conversation keys to protect message content.

The app also includes profile photos, searchable conversations and friends, and a light or dark theme. It connects to the SecureChat backend for account, friend, and conversation services.
